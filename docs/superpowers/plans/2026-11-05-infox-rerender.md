# InfoX 재렌더·재업로드 구현 계획

승인된 대화 계획을 구현한다. 같은 영상에 회차를 추가하며 과거 기록과 링크를 보존한다.
이전 기준일을 기본값으로 유지하고 실행 전에 변경할 수 있게 한다.
실패·확인 필요 뒤에도 기존 작업의 종료가 확인되면 새 회차를 허용한다.
작업 ID 없는 접수 불명확, 진행 중 작업과 미지원 상태는 차단한다.
원격 API와 검증기는 재사용하며 변경 요청은 회차별 한 번만 전송한다.

- [x] 회차 모델, 이력 저장, 외래키 보존 마이그레이션과 DB 배타 검사
- [x] 안전 사전 검사, 새 회차 API, 기존 API 호환
- [x] Vue 준비 화면, 날짜 기본값, 이력과 응답 유실 복원
- [x] 회귀 fixture, 전체 자동 검사, 브라우저 검사, 문서와 최종 리뷰

실행: 기존 Python/FastAPI/SQLite, Vue/TypeScript 구조를 유지한다.
실제 렌더/업로드 호출은 자동 검사에 포함하지 않는다.
