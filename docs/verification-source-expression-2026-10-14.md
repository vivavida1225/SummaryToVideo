## 모의 전송 검증

- 최초 생성, 형식·분량 자동 보정, 사용자가 요청한 재생성에서 원문 표현 보존 지침이 실제 전송되는지 검사했다.
- 수치 한국어 전사 켜짐·꺼짐 모두 최초 원문이 유지되는지 확인했다. 자동 보정은 직전 원응답을, 검토 작업의 사용자 재생성은 저장된 대본을 이전 응답으로 전달하는 기존 동작도 확인했다.
- 수치 전사가 켜진 경우 전사된 대본을 저장하지만 원시 응답과 검증 실패 원응답은 그대로 보존한다. 기존 강조·확산 검출과 `needs_review` 처리 테스트를 유지했다.
- 관련 테스트: `tests/test_compression.py`, `tests/test_strength_validation.py`, `tests/test_strength_flow.py` — **115개 통과**.
- 변경 전 전체 백엔드 기준선: **347개 통과, 1개 실패**. 기존 `test_equivalent_index_expressions_are_accepted`의 한 예제가 484자로 최소 490자에 미달했다. 이번 변경 범위에서는 수정하지 않는다.
- 변경 후 전체 백엔드: **350개 통과, 1개 실패**. 실패 항목과 원인은 변경 전과 동일하며 새 실패는 없다. 실행 명령은 `.venv\Scripts\python.exe -X utf8 -m pytest -q --tb=short`다.
- `git diff --check` 통과.
- 별도 읽기 전용 코드 리뷰에서 수정이 필요한 지적 사항은 없었다. 지침 연결·원문 전달·검토표 인용을 확인했으며, 리뷰어는 테스트를 별도로 재실행하지 않았다.

## 기존 생성 결과의 원문 표현 검토

검토 자료는 [기존 직렬화 원문](../tests/fixtures/1013_strength_serialized.txt)과 [기존 모델 원응답](../tests/fixtures/1013_strength_raw.txt)이다. 아래 평가는 기존 결과를 원문과 비교한 수동 검토이며, 새 지침으로 생성한 결과의 평가가 아니다.

| 원문 표현 | 기존 생성 결과의 대응 표현 | 핵심 표현 보존 여부 | 새 지침에 따른 작성 기준 |
|---|---|---|---|
| 시장 리스크 오프 심화 | 위험자산 회피 심리가 크게 번졌습니다. | 미보존: 핵심 용어·동사 대체와 강조·확산 추가 | 시장 리스크 오프가 심화됐습니다. |
| 외국인 대규모 순매도 및 프로그램 매도 압력 | 외국인의 대규모 순매도와 프로그램 매도 압력이 | 보존: 핵심 용어·수식어 유지, 조사·연결 보완 | 이 핵심 표현을 유지하고 원문 근거로 문장을 완성한다. |
| 유동성 축소 | 유동성을 급격히 축소시켰습니다. | 부분 보존: 유동성·축소는 유지했으나 원문에 없는 ‘급격히’ 추가 | ‘급격히’를 추가하지 않고 원문의 ‘유동성 축소’를 활용한다. |

## 검증의 한계

모의 테스트는 지침 전달과 기존 처리 흐름을 검증한다. 실제 유료 모델 호출은 수행하지 않았으며, 새 지침으로 생성한 대본의 표현 준수율은 측정하지 않았다. 원문 표현 보존 지침이 모든 유사어 대체를 자동 차단하는 것은 아니다. 실제 생성 결과는 최초 원문과 비교해 최종 검토한다.
