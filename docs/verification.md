- 결과: `outputs/20260911_093218_597402_2767fafc/`.
- 최종 파일과 Windows 클립보드 본문 일치 확인 (LF/CRLF 개행만 정규화하여 비교).
- 다른 프로세스가 유효한 창 핸들로 클립보드를 잠근 상태에서 약 0.67초 안에 재시도 종료 및 오류 반환 확인.
- Windows 네이티브 신뢰 저장소로 TLS 연결 검증. 인증서·호스트 이름 검증을 유지함.
