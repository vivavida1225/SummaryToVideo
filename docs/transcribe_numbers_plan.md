# 대본 수치 한국어 전사 기능 계획

## 요약

상단의 `로컬 연결` 표시를 **‘수치 한국어로 바로 전사’** 체크박스로 교체한다. 옵션을 켜고 변환하면 대본의 일반 수치를 한국어 독음으로 작성한다. 옵션을 끄면 현재 생성·검증 동작을 유지한다.

## 구현

- 체크박스는 기본값을 **끔**으로 두고 브라우저에 선택값을 저장한다. 일반 변환과 `myasset` 불러오기 후 자동 변환 모두 요청에 `transcribe_numbers: boolean`을 전달한다. 서버는 이 값을 작업 기록에 저장하며, 해당 작업의 재시도에는 저장된 값을 사용한다.
- 옵션이 켜졌을 때만 원본 프롬프트와 실행 시 출력 규칙에 전사 지침을 적용한다. 정수는 한국어 수사로, 소수점 아래는 자리별로 읽는다. 예: `6884.15` → `육천팔백팔십사 점 일오`. 숫자가 포함된 고정 용어·상품명은 원문 표기를 유지한다.
- 검증 단계에서 원문 코스피·코스닥 종가의 정답 독음을 코드로 계산한다. 1장면에서 각 시장의 **최종 종가**에 해당하는 구간을 확인하고, 독음이 다르면 그 구간만 정답으로 교체한 뒤 기존 형식·등락률·방향·490~550자 검증을 다시 수행한다. 이 수정 때문에 종가 오류만으로 모델에 자동 재요청하지 않는다.
- 모델이 남긴 일반 수치의 숫자 표기는 안전하게 식별되는 경우 코드로 전사한다. 종가의 수정 위치나 다른 수치의 경계를 확실히 판단할 수 없으면 추측해서 고치지 않고 대본과 사유를 **검토 필요** 상태로 표시한다. 원본 모델 응답과 수정된 최종 대본은 구분해 보관한다.
- 독음 모드에서도 등락률과 방향을 원문과 대조하도록 검증기를 확장한다. 그 밖의 기존 자동 보정 규칙과 분량 상한 처리 방식은 유지한다. 화면 안내와 README에도 옵션의 적용 범위 및 검토 필요 조건을 반영한다.

## 검증

- 백엔드: `6884.15`의 정확·오류 독음, 소수 자릿수와 `0`, 코스피·코스닥 값 뒤바뀜, 장중 지수와 종가의 구별, 등락률·방향, 수정 후 글자 수, 위치가 불명확한 대본, 기존 작업 기록과 옵션 끔 경로를 테스트한다.
- 프런트엔드: 체크박스 위치·기본값·저장, 일반 변환과 `myasset` 자동 변환의 요청값, 재시도 시 작업 옵션 유지, 좁은 화면에서의 표시를 확인한다.
- 전체 백엔드 테스트, 프런트엔드 테스트와 빌드, `git diff --check`를 실행한다.

## 가정

- ‘모든 수치’는 대본의 **일반적인 숫자 수치**를 뜻한다. `2차전지`처럼 원문 표기를 보존해야 하는 고정 용어·상품명은 제외한다.
- 실제 TTS 음성의 발음 자체는 자동 검증 대상이 아니며, 검증 대상은 TTS에 전달할 최종 대본의 독음이다.
