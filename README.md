# Market Brief — 로컬 시황 압축

HTML 시황을 장면별 평문으로 변환하고 Gemini 또는 GPT로 1분 영상용 5줄 낭독 대본을 만드는 Windows 앱입니다. Vue3 화면과 Python 서버가 함께 실행됩니다.

## 실행

새 컴퓨터에서는 먼저 **`install.cmd`**를 실행해 의존성을 준비할 수 있습니다. Node.js·Python을 미리 설치할 필요는 없습니다.

- 프로젝트 전용 Python 3.14.7과 Node.js 24.21.0의 설치 여부·버전을 확인하고, 없거나 버전이 맞지 않으면 다운로드하여 설치합니다.
- Python 가상 환경과 `requirements.txt` 패키지, 프런트엔드 npm 패키지를 준비하고 필요한 경우 화면을 빌드합니다. `.venv`의 Python 버전·기본 경로·실행 상태가 프로젝트 기준과 다르면 기존 패키지를 지우고 환경을 새로 생성합니다. 같은 기준의 정상 환경은 재사용합니다.
- 런타임은 `.tools/`, Python 패키지는 `.venv/`, 프런트엔드 패키지는 `frontend/node_modules/`에 설치됩니다. 시스템에 설치된 Node·Python이나 전역 PATH는 변경하지 않습니다.
- 최초 설치에는 인터넷 연결과 프로젝트 폴더 쓰기 권한이 필요합니다. 정상적으로 준비된 항목은 재사용하므로 다시 실행해도 됩니다.
- 설치만 진행하며 앱 서버·브라우저를 시작하거나 생성 API를 호출하지 않습니다. 완료 후 아래 순서대로 `start.cmd`를 실행하세요.
- 오류가 나면 `.runtime/launcher.log`를 확인하세요. 더블클릭 실행 시 결과 확인을 위해 창이 대기합니다. 터미널·자동화에서는 `install.cmd --no-pause`를 사용하며, 성공은 종료 코드 0, 실패는 0이 아닌 값입니다.

`start.cmd`도 동일한 자동 준비 기능을 사용하므로 별도 설치 단계를 생략하고 바로 실행할 수 있습니다.

1. 탐색기에서 **`start.cmd`**를 실행합니다. 준비가 끝나면 기본 브라우저가 열립니다.
2. 기본 입력은 클립보드의 HTML입니다. **클립보드 다시 읽기**, 직접 붙여넣기, 또는 **저장된 파일** 선택을 사용할 수 있습니다. 파일은 미리 선택하지 않습니다.
3. **변환 및 1분 압축**을 누릅니다. 직렬화 원문과 대본은 화면에 표시되고 파일로 저장됩니다. 클립보드는 자동으로 변경하지 않으며, 각 결과의 **복사** 버튼을 눌렀을 때만 복사합니다. 검증 실패 대본도 경고와 함께 표시되며 수동으로 복사·다운로드할 수 있습니다.
4. 사용을 마치면 **`stop.cmd`**로 서버를 종료합니다. 브라우저 탭만 닫으면 서버는 계속 실행됩니다.

최초 환경 준비에는 인터넷 연결이 필요합니다. 화면과 HTML 변환은 로컬에서 동작하며, 압축할 때 직렬화된 뉴스 본문을 Gemini로 전송합니다. 화면을 여는 것만으로 API를 호출하지 않습니다.

## myasset 원문 불러오기

**원문 선택** 오른쪽의 **myasset에서 불러오기**를 누르면 원문을 가져온 뒤 **변환 및 1분 압축**까지 자동 실행합니다. 현재 선택한 시작 모델을 사용합니다.

- 제목 영역 맨 오른쪽의 **불러오기 설정**에서 날짜와 `gubun`을 변경할 수 있습니다. 기본값은 **한국 시간 기준 오늘 / gubun=30**입니다. 새로고침하면 기본값으로 돌아옵니다.
- myasset 주소의 `id=1`, `cond=list`는 고정입니다. 서버가 해당 페이지의 `div.contWrap` 내부 HTML을 검사하여 기존 HTML 입력창에 표시합니다. 저장된 파일 탭에 있어도 성공하면 HTML 입력 탭으로 전환합니다.
- 게시글 본문이 없거나 통신이 실패하면 안내를 표시하고 기존 입력과 결과를 유지합니다. HTTP 200 응답이어도 홍보 영역만 있는 페이지는 원문으로 처리하지 않습니다. 날짜 또는 gubun을 변경하거나 게시 후 다시 시도하세요.
- 가져온 뒤 작업 시작에 실패하면 원문은 입력창에 남습니다. **변환 및 1분 압축**으로 다시 실행할 수 있습니다.
- 가져오는 중에는 입력·설정 변경과 중복 실행을 막습니다. 원문 가져오기와 결과 생성은 OS 클립보드를 자동 변경하지 않습니다.
- 2026-09-17 게시글의 실사이트 확인에는 `gubun=1`을 사용했습니다. 앱 기본값은 **30**이며, 미게시 시 다른 gubun으로 자동 대체하지 않습니다.

분량 초과로 검토가 필요하면 기존과 같이 대본을 표시하고 멈춥니다. **대본 재생성**을 눌러야 다시 생성합니다.

화면 빌드 후 가져오기·오류 복구·자동 실행·반응형 배치의 모의 브라우저 검사는 다음 명령으로 실행합니다. 생성 API와 OS 클립보드는 사용하지 않습니다.

```powershell
.\.venv\Scripts\python.exe -m tests.myasset_browser_smoke
```

## API 키와 결과

**압축 결과(대본)는 결과란을 클릭해 바로 수정할 수 있습니다.** 생성이 끝난 대본은 키보드로 편집하면 자동 저장되며, 글자수도 즉시 바뀝니다. 한글 조합 중에는 조합이 끝난 뒤 저장합니다. **압축 결과 복사**와 **압축 결과 다운로드**는 최신 수정본의 저장을 확인한 뒤 실행하므로, 입력 직후 눌러도 수정한 내용이 반영됩니다. 저장된 수정본은 새로고침하거나 서버를 다시 실행해도 유지됩니다.

저장 오류가 발생하면 입력한 대본을 유지하고 **저장 다시 시도**를 표시합니다. 저장에 실패한 상태에서는 이전 대본을 대신 복사·다운로드하지 않습니다. 다른 화면에서 같은 대본을 수정한 경우에는 충돌을 안내하므로, 현재 입력을 별도로 보관한 뒤 새로고침하세요. 미저장 내용이나 진행 중인 저장이 있으면 페이지를 떠날 때 브라우저 확인을 요청합니다.

직접 수정한 문장은 그대로 저장하며 자동 재생성하지 않습니다. 기존 생성 상태·검증 메시지는 생성 당시의 기록으로 구분해 표시합니다. 수정본은 실행 폴더의 `edited_compressed.json`에 본문·저장 버전·수정 시각을 함께 저장합니다. 원래 생성된 `compressed.txt`는 보존하고, 화면과 복사·다운로드에는 최신 수정본을 사용합니다. 정돈된 시장 원문은 읽기 전용입니다.

편집·저장·복사·다운로드·재조회는 실제 로컬 API와 임시 저장 폴더로 검증할 수 있습니다. 화면 빌드 후 아래 명령을 실행하며, 생성 API와 OS 클립보드는 사용하지 않습니다.

```powershell
.\.venv\Scripts\python.exe -m tests.edit_narration_browser_smoke
```

- OpenAI는 단일 `OPENAI_API_KEY`를 사용합니다. 비어 있지 않은 프로세스 환경 변수 값을 우선하고, 없으면 프로젝트 `.env`에서 읽습니다. Gemini는 기존 `.env`의 `GEMINI_API_KEY_1`, `GEMINI_API_KEY_2`, `GEMINI_API_KEY_3`을 번호순으로 읽으며 빈 키는 건너뜁니다. 화면에는 선택한 공급자의 키 설정 상태만 표시합니다. 새 환경이라면 `.env.example`을 `.env`로 복사한 뒤 값을 입력합니다.
- 오른쪽 위 System Status의 **시작 모델** 드롭다운에서 모델을 선택합니다. 기본값은 **GPT 6.1 Sol**(`gpt-6.1-sol`)입니다. 목록은 GPT 6.1 Sol → GPT 6.1 Terra(`gpt-6.1-terra`) → GPT 6 Luna(`gpt-6-luna`) → Gemini 3.8 Flash(`gemini-3.8-flash`) → Gemini 3.6 Flash(`gemini-3.6-flash`) → Gemini 3.5 Flash-Lite(`gemini-3.5-flash-lite`) 순서입니다.
- 2026-10-14 확인한 [Google 지원 중단 공지](https://ai.google.dev/gemini-api/docs/deprecations?hl=ko)에 따라, 3.8로 자동 라우팅되는 `gemini-3.7-flash`는 선택·자동 전환 목록에서 제외합니다. 브라우저에 저장된 3.7 선택은 현재 기본값 Sol로 갱신하며, 기존 API 요청·과거 작업 재시도의 3.7 ID도 3.8로 전환합니다. 기존 작업 기록은 그대로 보존합니다.
- 선택한 모델부터 **같은 공급자 안에서만** 아래쪽으로 폴백합니다. Sol은 Sol → Terra → Luna, Terra는 Terra → Luna, Luna는 Luna만 호출합니다. Gemini 3.8은 3.8 → 3.6 → 3.5 Flash-Lite 순서이며, GPT와 Gemini 사이에는 자동 전환하지 않습니다. 선택값은 같은 브라우저·앱 주소의 `localStorage`에 저장되어 새로고침·재접속 시 복원되며, 저장값이 없거나 지원하지 않는 값이면 Sol로 시작합니다. 기존에 저장된 유효한 Gemini·GPT 선택은 유지합니다. 브라우저 저장소가 차단되면 현재 화면에서만 선택값을 유지합니다.
- 작업 중에는 모델 선택을 잠급니다. 자동 폴백은 저장된 시작 모델을 바꾸지 않으며, 진행 패널에는 실제 호출·응답 모델과 전환 사유를 표시합니다. 키 값은 브라우저·결과 파일·로그에 노출하지 않습니다.
- 결과는 `outputs/<실행시각_고유ID>/serialized.txt`와 `compressed.txt`에 저장됩니다. `compressed.txt`에는 검증 실패 대본도 보관될 수 있으므로, 성공 여부는 화면의 경고 또는 `metadata.json`의 상태·오류를 확인하세요. 메타데이터에는 시작 모델(`requested_model`), 현재·마지막 호출 모델(`model`), 시도한 모델 목록(`attempted_models`)과 시도 횟수도 남습니다.
- 심리·선호·우려의 추가 강조와 확산 표현 검출은 기본 활성화입니다. `심화·확대·증가`만으로 `크게·대폭·상당히·매우·급격히·극도로`를 보충하거나, 확산 근거 없이 `번졌다·퍼졌다·확산됐다`로 바꾸지 않도록 첫 호출과 보정 지침에 명시합니다. 코드는 등록된 대상·활용형과 같은 사실의 원문 근거를 좁게 대조하며, 근거를 확인할 수 없으면 추가 API 호출 없이 `needs_review`로 전환합니다. 대본과 원시 응답은 보존하고 사유는 기존 검토 화면과 `metadata.json`의 `validation_issues`에 표시합니다.
- 강조의 원문 대응은 정해진 표현만 인정합니다. 예를 들어 같은 대상의 `큰 폭·대폭`은 `크게`의 근거가 되지만, `리스크 오프 심화`나 다른 항목의 `공포지수 급등`은 회피 심리의 `크게`를 뒷받침하지 않습니다. 대상·주체·부정·전망 여부나 여러 사실의 대응이 불분명하면 정상적인 바꿔 쓰기도 검토 대상으로 남을 수 있습니다. 이 검출은 지수·종목·수급의 강도, 일반적인 의미·인과관계, 등록되지 않은 표현을 검증하지 않습니다. 사용자가 재생성을 요청할 때만 최초 원문과 강화된 보정 지침으로 다시 호출하며, 수동 편집 저장은 모델을 호출하지 않습니다.
- 정상 완료된 비어 있지 않은 API 텍스트 원응답은 `raw_response_N.txt`에 보관합니다. OpenAI의 생성 거부·미완료 응답은 transport 오류로 처리하여 대본으로 저장하지 않습니다. 검증에 실패한 원응답은 `invalid_response_N.txt`에도 보관합니다. `N`은 API 호출 시도 번호입니다.
- 자동 저장에 실패해도 생성된 결과는 현재 화면에서 다운로드할 수 있습니다. 서버를 종료하기 전에 다운로드하세요.
- 정상 결과 파일은 UTF-8, LF 개행의 본문을 저장합니다. Windows 클립보드에는 같은 본문을 Windows 개행으로 복사합니다. 진단용 API 원응답에는 모델이 출력한 구분자나 잘못된 형식도 그대로 남습니다.

화면의 다운로드 버튼은 **작업 생성일의 한국 시간(Asia/Seoul)**을 기준으로 파일명을 지정합니다. 과거 작업을 다시 다운로드해도 해당 작업의 생성일을 사용합니다.

| 다운로드 대상 | 파일명 | 예시 |
| --- | --- | --- |
| 직렬화 원문 | `YYMMDD_원본데이터.txt` | `260911_원본데이터.txt` |
| 압축 결과·검증 실패 대본 | `YYMMDD_대본.txt` | `260911_대본.txt` |

서버의 실행별 폴더에는 기존 이름인 `serialized.txt`와 `compressed.txt`로 저장됩니다.

## 오류 처리

호출 한도(429), 서버 오류(5xx), 408, 연결 오류·타임아웃, 빈 응답, 모델 없음·사용 불가(404)는 **같은 공급자의 같은 키로 다음 모델**을 즉시 호출합니다. OpenAI 출력 토큰 한도에 따른 미완료와 응답 본문의 `server_error`·`rate_limit_exceeded` 오류도 다음 GPT 모델로 전환합니다. 실패한 모델로 돌아가지 않고, 마지막 후보까지 실패하면 종료합니다. 기존 모델의 재시도 대기 지시는 다른 모델로 넘어갈 때 적용하지 않습니다.

Gemini의 `API_KEY_INVALID` 또는 인증/권한 오류(401·403)는 **같은 모델에서 다음 Gemini 키**로 전환합니다. 실패한 키는 해당 작업에서 다시 쓰지 않으며 모든 키가 소진되면 종료합니다. 같은 프로젝트의 여러 키는 호출 한도를 공유하므로 쿼타 오류에서는 키를 순회하지 않습니다. OpenAI는 단일 키만 사용하며 401·403 인증/권한 오류가 나면 즉시 종료합니다.

호출 상한은 **후보 모델 수 + 설정된 키 수 − 1 + 보정 1회**입니다. Sol 또는 Gemini 3.8부터 시작하고 해당 공급자의 키가 1개면 최대 4회입니다. 통신 오류만 이어지면 각 후보를 한 번씩 시도하고 마지막 후보 실패 시 종료합니다. 요청당 **60초**, 전체 **300초** 제한을 유지하므로 남은 시간이 없으면 후보나 보정 횟수가 남아도 종료합니다. 작업을 시작할 때 모델과 해당 공급자의 키 목록을 확정하며 SDK 내부 자동 재시도는 사용하지 않습니다.

OpenAI 호출은 공식 Python SDK의 Responses API를 사용합니다. 초기 설정은 `reasoning.effort=low`, `max_output_tokens=8192`(추론 포함), `store=false`이며 `temperature`·도구·스트리밍은 사용하지 않습니다. 공식 OpenAI 주소와 작업 시작 시 확정한 인증 키로 호출하며, SDK의 별도 환경 설정이 주소나 인증 헤더를 덮어쓰지 못하게 합니다. 프롬프트와 대본 검증·보정은 Gemini와 공유합니다. 모델 ID와 파라미터는 [OpenAI 공식 안내](https://developers.openai.com/api/docs/guides/latest-model)를 기준으로 합니다.

**550자를 초과한 대본은 자동 보정하지 않습니다.** 다른 지수·문장·형식 오류가 함께 있어도 `분량 확인 필요` 상태(`needs_review`)로 멈추고 생성된 대본과 모든 검증 내용을 표시합니다. 결과 패널에서 `551자 · 상한 550자보다 1자 초과`처럼 현재 글자수와 초과량을 확인하고 그대로 복사·다운로드할 수 있습니다. 새로고침하거나 서버를 재시작해도 이 상태와 대본을 유지합니다.

사용자가 **대본 재생성**을 눌렀을 때만 원문·기존 대본·초과량·검증 오류를 현재 선택 모델에 보내 보정합니다. 새 작업으로 저장하여 이전 대본도 보존합니다. 이 요청은 보정 1회를 사용한 것으로 처리하므로 통신 오류의 모델·키 폴백은 유지하지만 응답을 받은 뒤 추가 자동 보정은 하지 않습니다. 다시 초과하면 분량 확인 필요, 정상이라면 완료, 초과 없이 다른 검증에 실패하면 실패 상태로 종료합니다. 수동 재생성의 호출 상한은 **후보 모델 수 + 설정된 키 수 − 1**입니다.

초과가 없는 구분자·형식·문장·지수 오류와 글자수 부족에는 기존처럼 **최대 한 번** 자동 보정을 요청합니다. 최초 입력 원문, 이전 API 원응답, 확인된 모든 오류, 줄 수·글자 수와 장면 작성 규칙을 전달하며, 통신 오류로 폴백해도 이 보정 문맥을 유지합니다.

초과가 없는 응답이 보정 후에도 검증에 실패하면 작업 상태는 실패로 유지하고, 진행 상황 영역의 기존 위치에 경고를 표시합니다. 마지막 응답은 정상 대본과 같은 article 결과 패널에 **검증 실패 대본**으로 표시합니다. 명시된 장면 구분자는 개행으로 변환하며, 이 변환 결과를 `compressed.txt`에 저장하고 화면·수동 복사·다운로드에 공통 사용합니다. 실패 대본은 자동 복사하지 않습니다. 저장된 오류에는 내용 검토가 필요한 부분이 모두 포함되는 것은 아닙니다.

일반 요청 설정 오류(400 등)와 명시적인 생성 차단은 자동 재시도하지 않습니다. 폴백이 모두 실패하면 마지막 오류와 시도한 모델을 표시합니다. 보정 중 통신 오류로 종료되어도 마지막 초안은 수동 복사·다운로드할 수 있고 자동 복사하지 않습니다. **압축 다시 시도**는 현재 드롭다운의 모델과 원래 직렬화 결과를 사용하며 클립보드나 원본 파일을 다시 읽지 않습니다.

복사 버튼을 눌렀을 때 클립보드가 다른 프로그램에 잠겨 있으면 오류를 표시합니다. 잠시 후 복사 버튼을 다시 누르세요. 대본 생성·저장은 클립보드 쓰기 상태에 영향을 받지 않습니다.

## 입력 형식

`src` 아래의 `.txt` 또는 `.html` 파일을 선택할 수 있습니다. 파일은 UTF-8 또는 UTF-8 BOM이어야 하며 최대 5 MiB입니다. 클립보드는 HTML 소스 텍스트와 Windows HTML clipboard format을 지원합니다.

HTML에는 `<header>`를 포함하는 실제 뉴스 `.embedded-content`가 하나 있어야 합니다. `.summary-box`, `.summary`, `.indices/.index-card`, `section/h2`, `ul/li`의 `.key-info`와 `.key-detail`을 순서대로 변환합니다. 누락·중복 구조는 오류로 표시합니다. 참고 입력은 `src/0910/0910_html.txt`입니다. `src/0907/1.txt`는 이미 평문인 참고 자료여서 HTML 변환 입력으로는 사용할 수 없습니다.

기존 `prompts/html to input text.txt`의 명시된 규칙을 Python으로 구현했습니다. 입력 직렬화의 장면 구분자는 항상 `===`입니다. `prompts/compress_to_1min.txt`는 API 요청마다 다시 읽고 5줄 대본 출력 계약을 덧붙입니다. 편집 내용은 다음 호출에 반영됩니다.

## 대본 생성과 검증

압축 결과는 코드블록·번호·제목 없이 정확히 5줄입니다. 각 줄은 마침표로 끝나는 본문 1~2문장입니다. 첫 줄은 시장 내용으로 시작하고 마지막 줄은 보완 사실로 마무리하며, 고정 시작·종료 인사말을 요구하지 않습니다.

API에는 실제 줄바꿈이나 문자 그대로의 `\n` 대신, 5개 장면 사이에 `<SCENE_BREAK>` 구분자를 정확히 4개 출력하도록 요청합니다. 백엔드는 구분자 주변 공백을 정리하고 이를 개행으로 변환한 뒤 검증합니다. 화면·저장·복사·다운로드는 같은 변환 결과를 사용합니다. 구분자는 글자 수에서 제외합니다. 구분자 수 오류·빈 장면·장면 내부 개행은 보정 대상이며 경계를 추정하거나 문장을 임의로 재배치하지 않습니다. 기존 정상 5줄 응답도 허용합니다.

5줄은 시장 결과·장중 경로 → 외부 변수 → 주도 업종·주도 수급 → 투자주체별 수급·리스크 → 앞 장면에서 아직 설명하지 않은 보완 사실 하나 순서입니다. 마지막 장면은 원문에 있는 사실을 정보 전달형 톤으로 소개하고, 원문에 명시된 영향이 있을 때만 덧붙입니다. 시장 전체를 다시 정의·요약하거나 앞 장면을 반복하지 않으며, 미래 전망·관전·확인 권고도 제시하지 않습니다. 미사용 사실이 없으면 새 사실을 만들거나 반복하지 않고 짧은 전달 종료 문장으로 마무리합니다. 프롬프트는 시청자가 기억할 핵심 세 가지를 먼저 선택하도록 안내합니다.

최초 작성과 보정 모두 약어·기업명·상품명 등 고유명사를 사용할 때 원문의 표기를 유지하도록 지시합니다. 자연스러운 낭독 문장은 원문의 핵심 표현을 유지하면서 조사·어미·문장 연결만 최소한으로 다듬으며, 영문 약어를 발음대로 한글로 변환하거나 다른 약어로 바꾸지 않습니다. 수치의 대상·기간·단위·범위도 유지합니다. 예를 들어 전체 수출 350억 달러를 반도체 수출 350억 달러로 바꾸지 않도록 합니다. 이는 모델에 전달하는 작성 규칙이며, 현재 자동 검증기가 모든 약어·고유명사·일반 수치의 의미를 대조하는 것은 아닙니다.

최초 생성·자동 보정·사용자 재생성 모두 **원문의 핵심 용어·동사·수식어를 최대한 그대로 사용**하도록 지시합니다. 사실 선택·중복 제거·장면 재배치는 허용하며, 선택한 사실은 낭독에 필요한 조사·존댓말 어미·문장 연결만 최소한으로 다듬습니다. 예를 들어 `우려가 심화했다`는 `우려가 심화했습니다.`, `안전자산 선호 확대`는 `안전자산 선호가 확대됐습니다.`, `상대적 강세`는 `상대적인 강세를 보였습니다.`로 표현합니다. 자연스러움이나 분량 때문에 `크게 번졌습니다.`, `급격히 커졌습니다.`, `선방했습니다.`로 바꾸지 않습니다. 쉬운 설명과 시장 영향도 최초 원문에 있는 표현과 근거를 활용하고, 분량은 미사용 근거 보충 또는 중복·낮은 우선순위의 사실 제거로 조정합니다. 기존 금지 표현 규칙과 선택된 수치 전사 규칙은 우선 적용합니다.

원문 표현 보존은 작성 지침이며, 모든 바꿔 쓰기를 자동 차단하는 기능은 아닙니다. 기존 지수·형식·분량 및 등록된 심리·선호·우려의 강조·확산 검출 범위는 유지합니다. 보정도 이전 초안이 아니라 최초 원문의 표현을 기준으로 요청합니다. 생성 결과의 핵심 표현 보존 여부는 최종 편집 단계에서 원문과 대조해 확인하세요.

출력 대본에는 **한자 문자를 사용하지 않습니다**. 이 규칙은 최초 생성·자동 보정·사용자 재생성에 모두 적용하며, 한자가 있는 원문 표기를 보존하는 것보다 우선합니다. 의미가 확실한 한국어 표기를 사용하고 불명확한 고유명사의 독음을 추측하지 않도록 지시합니다. `시장`, `수급`처럼 한글로 쓴 한자어는 허용합니다.

검증은 장면 구분자 변환과 선택된 수치 처리 후의 대본 전체에서 기본·확장·호환 한자와 `〇`를 검사합니다. 검출되면 장면 번호·문자·코드 포인트·주변 문맥을 표시하고, 추가 자동 보정 없이 **검토 필요**로 멈춥니다. 다른 검증 사유도 함께 표시하며 대본과 원응답은 보존합니다. 클립보드는 자동으로 변경하지 않고 수동 복사·다운로드와 **대본 재생성**을 허용합니다. 입력 원문의 한자만으로는 경고하지 않으며, 과거 저장 결과를 소급 검사하지 않습니다. 직접 편집한 대본은 자동 재검증하지 않고 생성 당시의 검토 기록을 유지합니다.

문장 수, **490~550자 범위** 및 첫 줄의 지수별 종가·등락률·방향을 검사합니다. 목표는 500자입니다. 하한 미달은 자동 보정 대상이며, 상한 초과는 대본과 초과량을 표시한 뒤 사용자가 재생성을 요청할 때만 보정합니다. 천 단위 쉼표 차이, `%`와 ‘퍼센트’ 표기, `0.00%`의 ‘보합’ 표현은 허용합니다. ‘급락·폭락·내림세’, ‘급등·폭등·반등·오름세’도 등락 방향으로 인식하며, 입력과 반대 방향이면 거부합니다. 글자 수에는 숫자·공백·문장부호를 포함하고 개행만 제외합니다. 고정 인사말을 제거한 뒤에도 같은 범위를 적용하므로, 인사말이 차지하던 분량은 본문 설명에 사용할 수 있습니다. 자료 부족도 하한 검증의 자동 예외는 아니며, 사실을 지어내 분량을 채우지 않도록 지시합니다. 검증은 서술 전체의 사실성·인과관계를 보증하지 않으며, 내용의 충실성과 인포엑스 TTS 아나운서 ‘빠름’ 설정에서의 실제 낭독 시간은 최종 편집 단계에서 확인하세요.

새 출력 계약은 새로 생성하는 결과에 적용하며, 기존 저장 결과를 새 규칙에 맞춰 재작성하지 않습니다. 이전 검증 실패 기록에 `compressed.txt`가 없으면 마지막 `invalid_response_N.txt`를 불러와 표시·복사·다운로드할 수 있습니다. 해당 원응답에 명시적 장면 구분자가 있으면 조회 시 개행으로 변환하고, 과거 파일 자체는 수정하지 않습니다.

프롬프트 파일 수정은 다음 API 요청에 반영됩니다. 백엔드 코드나 앱 출력 계약·보정 지시 변경 후에는 `stop.cmd`로 종료하고 `start.cmd`로 다시 실행하세요. 프런트엔드 변경은 빌드가 필요하며, `install.cmd` 또는 종료 후 `start.cmd`로 준비한 다음 브라우저를 새로고침하세요.


`--fenced`를 추가하면 하나의 `text` 코드블록으로 감싼 출력을 생성합니다.

실제 생성 API를 사용하는 검사는 명시적으로 실행합니다. 기본값은 Sol이며 `--model`로 시작 모델을 지정할 수 있습니다. 해당 모델에서 실패하면 같은 공급자 안에서만 폴백합니다. API 사용량이 발생하며 결과는 파일로 저장합니다. 클립보드는 변경하지 않습니다.

```powershell
.\.venv\Scripts\python.exe -m tests.live_smoke --model gpt-6.1-sol
```

프런트엔드는 `frontend/`, 백엔드는 `backend/`에 있습니다. 세부 HTTP 계약은 `docs/implementation.md`를 참고하세요. API는 루프백에서만 열리며 작업·클립보드·다운로드 요청에는 앱 세션 토큰이 필요합니다.

초과 대본 화면과 수동 재생성의 브라우저 검사는 화면 빌드 후 실행합니다. 생성 API와 클립보드를 사용하지 않는 모의 HTTP 검사입니다.

```powershell
.\.venv\Scripts\python.exe -m tests.length_review_browser_smoke
```

모델 선택·공급자 키 표시·GPT 폴백 후 실제 모델 표시의 브라우저 검사는 다음 명령으로 실행합니다. 모의 API를 사용하며 유료 호출은 없습니다.

```powershell
.\.venv\Scripts\python.exe -m tests.provider_browser_smoke
```

Node의 전역 Web Storage 기능과 jsdom이 충돌하는 환경에서는 프런트엔드 테스트 전에 `$env:NODE_OPTIONS = "--no-experimental-webstorage"`를 설정합니다.

## 수치 한국어 전사 옵션

상단의 **수치 한국어로 바로 전사**를 켜면 새 변환과 myasset 자동 변환에서 일반 숫자 수치를 한국어 독음으로 요청하고 안전하게 판별되는 숫자 표기를 백엔드가 전사합니다. 기본값은 꺼짐이며 선택은 브라우저에 저장됩니다. `2차전지` 같은 고정 용어와 숫자가 포함된 상품명은 원문 표기를 유지합니다.

첫 줄의 코스피·코스닥 등락률은 방향을 나타내는 `오른`·`내린` 등의 동사와 중복되지 않도록 `플러스`·`마이너스` 부호를 읽지 않습니다. 이 조합이 포함된 응답은 검증에서 거부합니다.

이 옵션은 작업 기록에도 저장되어 재시도할 때 같은 설정을 사용합니다. 백엔드는 코스피·코스닥 최종 종가의 독음을 원문과 대조하고, 한 번에 특정할 수 있는 잘못된 종가만 바로잡습니다. 숫자 위치나 경계를 안전하게 판별할 수 없으면 원응답과 대본을 보관하고 **검토 필요**로 표시합니다. 글자 수와 등락률·방향 검증은 전사된 최종 대본을 대상으로 다시 수행합니다. 실제 TTS 음성의 발음 자체는 자동 검증하지 않습니다.
